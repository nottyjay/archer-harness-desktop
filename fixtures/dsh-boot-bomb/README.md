# dsh-boot-bomb

阶段 0 逃生口的本地坏插件：`apply()` 一挂载就抛错，DSH fail-loud，整棵树拒绝启动。

**不要放进 `packages/`**，否则 debug 会当内置插件发现，跳过用户插件时卸不掉。

## 怎么测

1. Archer 先正常进就绪页。
2. 设置 → 插件 → **载入本地插件**，选本目录（`fixtures/dsh-boot-bomb`）。
3. 服务会重启并失败。预期：
   - 日志能对上包名 → **恢复页**，主按钮「禁用此插件并继续检测」，次要有「跳过用户插件启动」。
   - 对不上包名 → **普通错误页**，主按钮「跳过用户插件启动」，列表里可对 `dsh-boot-bomb`「禁用并重试」。
4. 跳过成功后就绪页顶部有横幅「当前未加载用户插件」。
5. 测完：在恢复页禁用/卸载，或插件面板卸载。不要只关 skip 再完整启动，否则还会被它炸一次。
